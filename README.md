# Tayyaba Yaseen — Next.js Portfolio

Converted from the supplied HTML portfolio into a Next.js App Router project.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

The original visual design, embedded image assets, theme toggle, mobile navigation, 3D skills carousel, reviews/lightbox, contact form behavior, and social/WhatsApp links are preserved from the supplied HTML.
